# Personal Information Manager 🧑‍💻

A simple **Python beginner project** that displays personal information, accepts user input, and calculates age in months.

## 📌 Project Overview

The **Personal Information Manager** is a basic Python program created to practice fundamental Python concepts such as:

* Variables
* Lists
* User input
* `while` loops
* Conditional validation
* Arithmetic operations
* f-strings
* Console output

The program stores personal details such as name, degree, age, city, hobby, and interests. It also asks the user for their favorite car and favorite color.

## 🚀 Features

* Displays a welcome message
* Stores personal information
* Accepts favorite car from the user
* Accepts favorite color from the user
* Validates empty inputs
* Calculates age in months
* Displays all collected information
* Shows a goodbye message

## 🛠️ Technologies Used

## 💻 How It Works

The program first displays the title **"PERSONAL INFORMATION MANAGER"** and then stores basic information such as name, degree, age, city, hobby, and interests.

It then asks the user:

```text
What's your favorite car?
What's your favorite color?
```

If the user leaves either field empty, the program asks them to enter a valid value.

The program calculates age in months using:

```python
age_in_months = age * 12
```

and displays the complete information at the end.
